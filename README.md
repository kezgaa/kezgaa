# Simple Storage Smart Contract

This repository contains a simple smart contract written in Solidity.

## File
- `SimpleStorage.sol`

## Tools
- Written and tested using [Remix Ethereum](https://remix.ethereum.org/)

## How to Use
1. Open [Remix](https://remix.ethereum.org/).
2. Copy the code from `SimpleStorage.sol` into a new file in Remix.
3. Compile the contract.
4. Deploy it to a test network (e.g., JavaScript VM or Injected Web3 with MetaMask).
